# GPS Desktop Sound Licenses

## 1. Default Generated Sound Theme (`assets/sounds/default/`)

All sound files in the `assets/sounds/default/` directory are original works programmatically generated by `scripts/gen-sounds.py` using mathematical signal synthesis (sine, triangle, exponential damping, and physical harmonic modeling).

- **Author**: GPS Desktop Project
- **License**: Creative Commons Zero v1.0 Universal (CC0 1.0) Public Domain Dedication
- **Rights**: You can copy, modify, distribute, and perform the work, even for commercial purposes, all without asking permission.

### Included Sounds:
- `chime.ogg`: Soft, warm notification chime (A5 + harmonics)
- `critical.ogg`: Double bright chime (C6 -> E6)
- `agent-permission.ogg`: Distinct rising two-tone (D5 -> A5) for agent approval
- `agent-permission-reminder.ogg`: Gentle repeating variant of agent permission prompt
- `agent-done.ogg`: Descending resolution chime (C6 -> G5 -> C5)
- `bell.ogg`: Resonant acoustic desk bell for task reminders
- `pop.ogg`: Quick organic bubble pop for download completion
- `blip.ogg`: Low-frequency warning blip for errors
- `tick.ogg`: Ultra-short mechanical haptic tick for volume changes
- `shutter.ogg`: Camera shutter snap
- `record-start.ogg` / `record-stop.ogg`: Microphone/recording status chirps
- `lock.ogg` / `unlock.ogg`: Mechanical latch and unlock sounds
- `battery-low.ogg`: Low battery pulse warning
- `plug.ogg` / `unplug.ogg`: Power connection / disconnection chirps
- `device-connect.ogg` / `device-disconnect.ogg`: Hardware peripheral connect tones
- `dnd-on.ogg` / `dnd-off.ogg`: Do Not Disturb mode toggle chimes
